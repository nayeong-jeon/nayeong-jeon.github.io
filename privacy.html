2. 계산기 입력 정보

계산기에 입력하는 정보는 본인 월 통상임금, 자녀 생년월일, 본인의 육아휴직 시작일·종료일(분할 사용 시 각 기간), 6+6 조건 입력 시 배우자 월 통상임금 및 배우자의 시작일·종료일(분할 사용 시 각 기간), 선택한 급여 제도와 18개월 연장 요건 선택입니다. 이 값들은 계산을 위해 방문자의 브라우저 메모리에서만 사용됩니다. 계산은 페이지 안의 JavaScript에서 처리하며, 사이트 코드에는 이 값을 서버나 외부 서비스로 보내는 네트워크 요청 기능이 없습니다. 이 값들을 쿠키·localStorage·sessionStorage 등에 저장하지도 않습니다. 입력값은 새로고침하거나 페이지를 닫으면 사라집니다.

입력 필드에는 계산기 값을 폼 전송용으로 식별하는 name 속성이 없습니다. 계산 동작은 폼 기본 전송을 막도록 구현되어 있으며, 스크립트가 실행되지 않는 경우에도 입력값이 URL에 붙어 전송되지 않도록 구성했습니다.

정적 사이트는 GitHub Pages에서 제공됩니다. 페이지 접속 시 호스팅 사업자는 접속을 처리하기 위해 IP 주소, 요청한 페이지, 접속 시각, 브라우저·기기 정보 등 서버 로그를 처리할 수 있습니다. 이는 계산기 입력값과 별개입니다.

3. 쿠키와 제3자 서비스

분석 도구, 광고 태그, Google AdSense 스크립트는 현재 페이지 코드에 포함되어 있지 않습니다. 다만 공통 스타일에서 Google Fonts의 스타일시트와 글꼴 파일을 요청합니다. 따라서 페이지를 열면 브라우저가 Google Fonts 서버에 연결할 수 있고, Google은 해당 요청의 IP 주소, 브라우저 정보, 요청한 페이지 등 네트워크 정보를 처리할 수 있습니다. 계산기 입력값은 이 요청에 포함되지 않습니다. 사이트 자체 코드는 쿠키를 설정하지 않으며, Google Fonts 또는 GitHub Pages의 처리·기술적 쿠키 여부는 각 서비스의 정책을 따릅니다.

고용24·국가법령정보센터·고용노동부·Instagram 등의 외부 링크는 사용자가 직접 링크를 누르기 전에는 해당 외부 사이트를 불러오지 않습니다. 링크를 누르면 해당 사업자가 접속 정보를 처리할 수 있습니다.

공식 제도 확인과 운영자 문의를 위해 외부 웹사이트로 연결합니다. 운영자 문의 계정은 @dalcong_mommy이며 실제 연결 주소는 instagram.com/dalcong_mommy입니다. 외부 사이트에서 이루어지는 개인정보 처리는 각 서비스의 개인정보 처리방침과 쿠키 정책을 따릅니다.

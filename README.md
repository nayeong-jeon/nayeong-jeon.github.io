# 육아휴직 급여 계산기

달콩맘(@dalcong_mommy)의 대한민국 육아휴직 급여 계산기입니다. 월별 급여를 추정하고 신청 가이드를 제공하는 정적 웹사이트로, 별도 빌드 도구 없이 `index.html`을 열거나 GitHub Pages에 배포할 수 있습니다.

## 실행

ES module을 사용하므로 로컬 웹 서버를 통해 실행합니다.

```sh
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`을 엽니다.

## 배포 (GitHub Pages)

1. 공개 저장소 `nayeong-jeon/nayeong-jeon.github.io`의 `main` 브랜치에 파일을 올립니다.
2. **Settings → Pages**에서 배포 소스를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 설정합니다.
3. 배포 주소는 `https://nayeong-jeon.github.io/`입니다.

## 계산 기준 및 유의사항

`calculator-core.mjs`가 일반(1~3개월 100%·250만 원, 4~6개월 100%·200만 원, 7개월 이후 80%·160만 원), 6+6(첫 6개월 상한 250/250/300/350/400/450만 원), 한부모 특례(첫 3개월 100%·300만 원, 4~6개월 100%·200만 원, 이후 80%·160만 원) 계산을 담당합니다. 하한은 월 70만 원이며, 입력한 실제 날짜·분할 사용 및 부분 월 비례 계산을 반영합니다.

계산 기준일은 2026년 11월 5일입니다. 6+6과 18개월 연장액은 자격을 확정하지 않고 조건 충족 가정액으로 표시합니다. 2025년 이전 시작 휴직 및 연장 자격이 확인되지 않은 12개월 초과 휴직은 자동 계산하지 않습니다. 실제 자격·경과규정·지급액은 관할 고용센터에서 확인하세요.


## 광고 및 애드센스

사이트에는 현재 광고 코드나 게시자 ID가 포함되어 있지 않습니다. 애드센스에 가입한 뒤 사이트 검토가 승인되면 애드센스에서 발급한 코드를 직접 추가해야 합니다. 승인 전 광고 코드를 임의로 넣거나 게시자 ID를 추측해서 사용하지 않습니다. `nayeong-jeon.github.io`는 GitHub에서 제공하는 무료 주소이며, 개인 도메인을 구입한 주소는 아닙니다. 애드센스의 사이트 등록·소유권 확인 과정에서 호스팅 플랫폼 주소가 허용되지 않으면 개인 도메인 없이 등록이 어려울 수 있습니다. 광고를 시작할 때는 개인정보처리방침, 동의 설정, ads.txt 및 광고 배치도 실제 계정 지침에 맞춰 갱신해야 합니다.

# 육아휴직 급여 계산기

달콩맘(@dacong_mommy)의 대한민국 육아휴직 급여 계산기입니다. 월별 급여를 추정하고 신청 가이드를 제공하는 정적 웹사이트로, 별도 빌드 도구 없이 `index.html`을 열거나 GitHub Pages에 배포할 수 있습니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다.

## 배포 (GitHub Pages)

1. GitHub에 `육아휴직급여계산기`라는 이름으로 공개 저장소를 만듭니다.
2. 이 폴더의 파일을 저장소 루트에 올립니다.
3. 저장소의 **Settings → Pages**에서 배포 소스를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 설정합니다.
4. 배포가 완료되면 Pages 설정에 표시되는 주소에서 사이트를 확인합니다.

## 계산 기준 및 유의사항

현재 계산 로직은 일반 급여(첫 3개월 월 상한 250만 원, 4~6개월 200만 원, 7개월 이후 160만 원), 6+6 부모육아휴직제(첫 6개월 상한 200만~450만 원), 한부모 특례(첫 3개월 상한 300만 원)를 가정합니다. 입력한 월 통상임금과 각 월 상한 중 낮은 금액으로 월별 추정액을 계산합니다.

이 계산기는 월 전체 사용을 가정한 간이 추정치이며 일할 계산, 실제 자격 심사, 사업장·개인별 임금 산정 및 제도 변경을 반영하지 않습니다. 법령이나 고시가 변경될 수 있으므로 실제 신청 전 고용24와 고용노동부에서 적용 시점의 최신 조건을 확인하세요. 안내 페이지 역시 법정 신청기한이나 서류를 확정적으로 안내하지 않고 공식 확인을 권고합니다.

## 광고 및 애드센스

사이트에는 현재 광고 코드나 게시자 ID가 포함되어 있지 않습니다. 애드센스에 가입한 뒤 사이트 검토가 승인되면 애드센스에서 발급한 코드를 직접 추가해야 합니다. 승인 전 광고 코드를 임의로 넣거나 게시자 ID를 추측해서 사용하지 않습니다. GitHub Pages의 기본 `github.io` 주소는 애드센스 사이트 등록에서 제한될 수 있으므로, 등록 화면에서 지원하지 않는다고 표시되면 별도 개인 도메인을 연결하는 방법을 검토하세요. 광고를 시작할 때는 개인정보처리방침, 동의 설정, ads.txt 및 광고 배치도 실제 계정 지침에 맞춰 갱신해야 합니다.
